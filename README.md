# AUDash 

*Because why not?*

A web app designed for **Dr. B.R. Ambedkar University Delhi (AUD)** students to easily view, search, and manage academic timetables and class schedules in real time.

---

## Getting Started

Python is required to run this project.

```bash
# clone the repository
git clone [https://github.com/Msingh-207/AUDash.git](https://github.com/Msingh-207/AUDash.git)
cd AUDash

# install requirements (Flask, flask-cors, etc.)
python -m pip install -r requirements.txt

# run the API server
python api/main.py
